# 小哈语音的程序、记录与备份

0.3.6 起使用完整的“小哈语音工具包”文件夹：双击其中“小哈语音.app”打开，移动或备份时保留整个文件夹。桌面或 Applications 中的替身仅是启动入口，单独复制入口不能带走资料。

| 内容 | 工具包内位置 |
| --- | --- |
| Mac 程序 | 小哈语音.app |
| 独立运行组件 | Runtime、Components |
| 小哈完成文字 | Data/history.json |
| 迁入的成功历史与原始统计字段 | Data/imports/shandianshuo/records.json |
| 闪电说完整文字记录归档（含失败、空结果） | Data/imports/shandianshuo/archives |
| 待恢复录音与文字草稿 | Data/recovery |
| 启停键、静默与窗口设置 | Data/settings.json |
| 剪贴板、网络和日志设置 | Data/runtime-settings.json |
| 生效词库及未完成编辑草稿 | Data/corrections.json、corrections-draft.json |
| 工作台与账号同步本机状态 | Data/desktop |
| 本机识别身份 | Data/recognition |
| 元数据运行日志 | Data/logs |

统计由完成记录的字数、时长、时间与来源汇总，不依赖一个手工累加的总数。已有数据全部保留；待恢复录音不计成功统计。成功录音只保留文字及统计。闪电说原音频、截图和附件仍留在原软件位置，没有另行复制这些媒体。

从“应用设置 → 完整备份与恢复”创建 ZIP，会校验整个程序与 Data。先结束录音并等待整理完成；失败不会替换同名旧备份。解压 ZIP 得到完整工具文件夹。应用内恢复会合并历史、按编号去重，当前较新的记录优先；冲突原件保存在 Data/restore-preserved，恢复前的整个 Data 也另行保留。旧设置不自动覆盖当前设置。

个人备份含历史、词库和识别身份，只用于本人恢复。给别人使用请选择不含个人 Data 的干净程序包，让对方明确初始化独立身份。输入法兼容通道不要求匹配官方输入法程序或网页账号，但没有官方开放接口的长期稳定保证；初始化不等于识别实测，认证拒绝后不自动更换身份重试。

API 密钥和同步令牌保存在操作系统安全存储中，不导出到 ZIP。换 Mac 后需重新授权三项系统权限、重新设置开机自启，并重新填 API 凭证或登录同步账号。首次加载运行组件可能较慢。本文说明 Mac arm64 基线。Windows 使用独立的原生客户端与版本归档，具体以其分支说明为准；云服务仍未开通。

日常新记录写入自己工具包的 Data。程序基线使用 Git 标签保留，干净安装包与个人完整备份分别保存。关键原生源码随工具附带，完整可构建源码保存在项目仓库。
