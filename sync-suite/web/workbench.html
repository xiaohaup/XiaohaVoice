  1. 开通流式语音识别 2.0，确认资源类型。 语音工作台 ↗
  2. 创建 API Key，填入上方；旧版使用 App ID 和 Access Token。 创建 / 管理密钥 ↗

连接测试不传音频。识别测速会发送约 1 秒的内置合成语音，使用你的 API 额度；不开麦，不计入历史和统计。

这台设备怎么连接检查中
  1. 选择豆包输入法通道，无需下载、启动或匹配官方输入法，也无需豆包网页登录。
  2. 首次使用点击“初始化这台设备”，程序通过兼容协议登记独立设备身份，并在本机保存；已有身份会直接复用。
  3. 允许麦克风和录音快捷键权限，按启停键说话，程序直接连接云端语音服务。

“测试连接”不发送音频；点击“识别测速”会通过豆包输入法通道识别约1秒内置合成语音，不打开麦克风、不计入历史统计，也不调用火山API。首次使用需先初始化这台设备。测试所选通道不必先保存，也不会切换实际录音通道。
