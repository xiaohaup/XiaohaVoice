# 小哈语音 Windows · 基础功能保留版

应用版本：**0.4.0-preview.1**；Windows 修订：**winfix6**；固定日期：**2026-10-21**。

本版本保留全局语音启停、实时文字悬浮窗、自动粘贴/仅复制、本机历史和统计、词库纠正、托盘以及备份恢复，供需要现有基础功能的人继续使用。后续新功能应在其他分支开发，本标签的代码和附件保持固定。

适用于 Windows x64。请下载此 Windows 标签的完整工具包 ZIP，核对同页 SHA256SUMS.txt，解压后运行；源码中的小型上游归档和依赖锁用于重新构建，Git 中不保存运行环境或大型动态库。发布工具包的 Data 为空，每位使用者需要配置自己的识别服务。

## 使用方式

构建后的整个文件夹是一个工具包。一起解压到自己的可写目录，双击 `小哈语音.exe`；以后可给这个 EXE 创建桌面快捷方式。不要只搬走一个 EXE，也不要放在系统保护目录中。

- 默认短按右 Alt 开始，再按同一个键结束；Esc 取消本次录音。普通鼠标操作、打字、切换窗口不停止收音。右 Alt 在部分键盘布局中承担 AltGr，可以在“语音输入”改用功能键、组合键或鼠标侧键。
- 浮窗只在录音、处理结果或主动预览时显示，不主动抢输入焦点。三种主界面主题，以及浅色、深棕、深绿、深蓝浮窗可独立选择或跟随主题。
- 结束时记住当前应用和输入位置。结果按结束顺序投递；保持输入框不变时触发 Ctrl+V，不按回车。如果识别期间你已点击或输入到别处，文字保留在本机历史和剪贴板，避免贴错位置。
- “剪贴板与粘贴”可选自动粘贴或仅复制；可保留最新转写，也可在粘贴后恢复原剪贴板。恢复模式遇到尚不能完整保存的位图/图元句柄格式会保留原内容并提示，不声称已完整还原。其他程序在等待期间复制的新内容不会被旧的恢复操作覆盖。
- 主窗口关闭后仍从系统托盘待命；完全退出用托盘菜单。“应用设置”分别控制登录自启、登录时静默、任务栏显示。首次启动不自动修改登录自启，不申请管理员权限。

## 首次配置识别服务

“语音输入 → 识别服务”有两个独立通道，测试结果分开保存，连接测试和内置短句测速均由你手动发起。

1. **豆包输入法兼容通道**：不是从安装好的输入法进程抽取接口，也不使用豆包网页账号。现有协议适配组件独立连接语音服务；只装豆包输入法不会自动完成握手。首次在设置页点“初始化这台设备”，确认后登记这台电脑的独立身份，再点连接测试和短句测速。这个接口没有官方开放接口的稳定承诺；服务拒绝时停止，不循环登记或自动换身份。Windows 端仍需验证服务实际接受和识别效果。
2. **火山引擎 API**：在页面每一步后面的工作台链接开通语音服务、创建 API Key，填写并保存。密钥进入本机 Windows 凭据管理器，页面默认隐藏，可点眼睛查看；以后留空继续使用已保存凭证。选择资源需与账号开通项相符。连接测试不打开麦克风；内置短句测速会上传附带的合成语音，并可能按服务计费。
3. 真实讲话测试使用系统默认输入设备。麦克风由 Windows 的隐私设置控制，不沿用 Mac 的输入监控或辅助功能授权。自动粘贴针对普通权限窗口；普通进程不能向更高权限窗口注入按键，不通过提权或改安全设置绕过。

网络代理只作用于本程序，可选系统、直连或手动。日志只保留有界的状态、耗时和字数，不保存识别全文、录音或密钥；可以关闭。账号同步界面沿用现有方案，在线服务尚未部署，因此不会自动同步到其他设备。

## 资料、完整备份和换电脑

- 程序在工具包根目录；运行组件在 `Runtime` 和 `Components`；历史、统计来源、词库、偏好、待恢复录音在 `Data`。统计从本机完成记录计算，不另造一份总数。
- “应用设置 → 完整备份”把程序、组件和 Data 一起打成带逐文件校验的 ZIP。保留程序外的备份位置；备份期间如资料有变化会停止，原资料保留。
- 同系统换电脑可解压完整备份，或在新工具包里选择“恢复备份”；历史按编号合并去重，当前新记录保留，冲突原件另存，恢复前的 Data 留作回退。
- **系统凭据不写入 ZIP**。换电脑后重新填写 API Key／登录同步账号，重新核对麦克风和自启；工具包里只保存非秘密配置。初始 Windows 发布包的 Data 为空，不包含 Mac 的个人资料、设备登记或凭证。可从本机闪电说历史显式迁入，按源编号去重；迁移不会覆盖本程序已有历史。
- 成功录音只保留文字；故障内容才进入待恢复录音。批量清理需在应用内确认，通过系统回收站处理，不永久删除文件。误触和无内容结束不会因“没有最终文字”一律被当成故障。

## 在目标 Windows 构建

需 Windows x64 和已存在的 64 位 Python 3.12—3.15；本基线在 Python 3.12.13 构建验证。不要安装到全局环境。

```text
py -3.12 -m venv .venv
.venv\Scripts\python.exe -X utf8 -m pip install -r requirements-windows.txt
.venv\Scripts\python.exe -X utf8 prepare_components.py
.venv\Scripts\python.exe -X utf8 vendor_opus.py devkit
.venv\Scripts\python.exe -X utf8 -m pytest -q tests
.venv\Scripts\python.exe -X utf8 verify_shared.py
.venv\Scripts\python.exe -X utf8 build_windows.py --output dist\XiaohaVoice-preview1
```

也可在建好 `.venv` 后双击 `build.cmd`。开发启动用 `start-dev.cmd`；它准备组件后启动原生宿主，不直接在浏览器访问源码 HTML。

构建从已冻结并核验哈希的 `upstream/source.zip` 生成 Windows 专用组件副本，使用已固定 SHA-256 的 Opus Windows DLL，分别打包无控制台主程序与后台运行组件。自检只在本机编码静音帧，不联网、不打开麦克风、不初始化设备、不修改自启。成品附带逐文件哈希、依赖许可证、构建报告；真实录音和粘贴另行验收。
