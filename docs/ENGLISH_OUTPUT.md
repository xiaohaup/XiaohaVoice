# 原文语音与英文输出 · 0.4.1 独立预览

这是纯语音版本的新分支，只回移可选英文输出。原Mac/Windows基础标签及附件保留，不含小哈工具的剪贴板历史、截图或快捷操作。

## 按键与结果

| 平台 | 开始 | 输出原文 | 输出英文 |
| --- | --- | --- | --- |
| Mac | 原语音启停键，默认右Option | 再按原启停键 | 短按右Command |
| Windows | 原语音启停键，默认右Alt | 再按原启停键 | 短按右Ctrl |

翻译结束键可以在“语音输入 → 英文输出”重新录入功能键、组合键或鼠标侧键，不能与原启停键冲突。它只在开启英文输出且正在录音时生效。Command/Ctrl参与复制粘贴等组合键、或长按修饰键，不作为短按翻译结束。

英文输出默认关闭。普通结束沿用原语音流程，没有新增翻译请求。选择英文结束后，先取得最终识别结果并应用本机词库纠正，再把这段文本交给翻译API，最后按原剪贴板/自动粘贴设置输出英文；不自动按回车发送。

原文先进入本机历史，英文关联在同一条记录下；字数、时长和次数只累计一次。翻译失败时保留原文并显示原因，按钮“重试翻译（复制）”只重试文本翻译并复制结果，避免再次粘贴到已经变化的位置。Esc可以取消正在等待的翻译，迟到的结果不投递。

## 配置自己的翻译API

1. 打开自己的[火山方舟工作台](https://console.volcengine.com/ark/region:ark+cn-beijing/overview)，开通所需语言模型。也可以使用其他兼容Chat Completions的服务。
2. 创建自己的API Key。无需把Key发到聊天、Issue或仓库。在应用的API Key输入框填入，保存后默认隐藏，点眼睛才显示。
3. API地址填写服务商的基础地址。方舟北京区域填写 `https://ark.cn-beijing.volces.com/api/v3`。程序补齐 `/chat/completions`；不要填 `/responses`。
4. 模型填写服务商提供的实际Model ID或自己的 `ep-…` 推理接入点ID。方舟示例：`doubao-seed-2-1-lite-260915`；可按自己的已开通模型更换，不把展示名称当成API ID。
5. 开启英文输出并保存，点“翻译测速”。它仅发送界面注明的固定测试句，不打开麦克风；可能消耗自己账号的额度。看到译文和耗时后再做真实讲话测试。

地址、模型、启用状态和结束键保存在本机Data，Key进入独立的系统安全存储。留空保存会继续使用已保存Key；换服务地址需填写该服务自己的Key。测速和语音使用同一个长驻本机服务缓存，避免每句话另起组件读取凭证；退出后缓存清空。新构建身份或系统安全策略变化时仍可能要求一次本人确认，不能保证所有机器永久无提示。

## 与小哈工具隔离

- Mac预览使用 `com.xiaoha.voice.standalone`，本机端口18766，独立登录启动项；Windows使用独立单实例名称、启动项和随机本机端口。
- 识别API、翻译API和同步凭证使用独立名称。不会读取、迁走或覆盖运行中小哈工具的Key。
- 下载包Data为空。升级原纯语音版时先备份整个旧工具包，再在新工具包显式恢复资料；原文历史结构兼容，旧文件不改写。Key换电脑后重新填写。
- 保留整个工具包文件夹。不要只复制App/EXE，也不要覆盖当前运行的小哈工具目录。同时运行两套使用同一全局快捷键的程序可能冲突；本次构建不会自动启动、安装或改任何原快捷键。
