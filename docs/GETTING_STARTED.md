# 首次使用

1. 选择对应系统的Release，下载完整工具包ZIP及SHA256SUMS.txt。不要把Source code当作直接可运行程序。
2. 解压到自己可写的目录，保留整个工具包文件夹。Mac双击“小哈语音.app”，Windows双击“小哈语音.exe”；可以创建替身／快捷方式。
3. 在“应用设置”核对系统权限。Mac需要麦克风、全局快捷键的输入监控与自动粘贴的辅助功能；Windows按系统麦克风隐私设置处理。不要照搬另一台电脑的权限登记。
4. 在“语音输入 → 识别服务”选择通道。输入法兼容通道首次明确初始化这台设备；API通道填写自己的凭证。先测连接，再手动识别测速；前者不等于已经识别成功。
5. 在空白测试文稿放置光标，按启停键说一句短话，再按同一键结束；检查文字是否完整、是否自动插入，以及剪贴板策略是否符合设置。
6. Mac默认右Option，Windows默认右Alt。某些键盘右Alt承担AltGr，可在设置改键。Esc取消；鼠标侧键需要实体设备自己确认。避免同时启用其他语音工具的同一个全局按键。

关闭主窗口仍从菜单栏／托盘待命；完全退出用菜单中的退出。开机自启、静默与Dock／任务栏显示分别控制，不会因打开软件自动录音。

安装包目前未完成平台正式签名／公证流程。核对源码和SHA256后按系统提示自行判断；不要为了运行软件关闭全局安全防护。其他电脑上的权限、快捷键和目标输入框仍需要自己的实测。
