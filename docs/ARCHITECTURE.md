# 项目结构与运行方式

## Mac 本机流程

```
全局按键／鼠标侧键 → 原生录音与会话 → 流式语音通道
                                          ↓ 实时文字
当前输入框 ← 系统粘贴 ← 本地词库纠正 ← 最终结果
                          ↓
                    本机历史与统计
```

- `mac-prototype/`：Swift AppKit / AVFoundation / WebKit，管理菜单栏、录音、快捷键、原生胶囊、窗口、权限和粘贴。
- `ime-channel-test/`：历史目录名保留；这里是当前识别适配器，不是需要另外启动的测试应用。输入法通道使用独立登记身份、WebSocket 与 Opus；火山通道走用户自己的正式 API。
- `sync-suite/desktop/`：仅本机接口、配置、凭证访问、历史统计、词库、导入、备份和同步客户端。
- `sync-suite/web/`：本机工作台与账号同步页面。配色可从组件文件读取，不必只为换颜色重新编译原生二进制。
- `sync-suite/server/`、`deploy/`：后续可部署的账号同步服务。当前本机录音不依赖云服务部署。
- `toolkit/runtime.py`：打包的 Python 模式入口；App 定位同文件夹的 Runtime 和 Components。

## 工具包与源码仓库

运行工具包由 App、Runtime、Components、Data、LICENSES、toolkit.json 和维护源码组成。Git 仓库保留源码／文档／锁定依赖；可执行程序与依赖放在 Release 安装包；私人 Data 永不进入干净安装包。

Data 保存完成文字、导入记录、词库、草稿、界面与录音设置、待恢复音频、本机识别身份。统计由成功记录重算；已经导入的闪电说历史属于个人 Data，本仓库只有导入程序，没有导入的个人内容。运行日志只记去内容元数据。

系统钥匙串／凭据库另存 API 密钥和同步会话；整包备份不会导出它们。恢复自己的旧备份与给另一人安装不同，另一人必须初始化独立设备身份。

## 准确性与边界

两种识别通道独立保存测试结果；连接测试验证握手，识别测速发送内置合成句，真人识别效果需要实际讲话判断。输入法兼容协议存在服务端改变的可能，不能保证未来一直可用。

粘贴采用系统投递并保留失败文字，不声称操作系统已确认目标收到全部文字；不发送消息。Mac 与 Windows 的快捷键／权限／剪贴板实现不同，因此各自维护版本和实机验收。
