# 后续路线

已发布基础版本继续保留原功能；本页描述计划，不表示已经可用。

## 0.5.0：剪贴板与常用语（方案阶段）

- Mac、Windows统一需求、核心规则和版本号，分别验证平台行为。
- 独立快捷面板，上方“剪贴板／常用语”，搜索、预览、键盘选择和插入后收起。
- 文字、图片、文件引用记录；类型筛选、置顶、去重、常用语分组、草稿自动保存和导入导出。
- 与原语音输入共用投递规则，不增加模型调用，不重复记录临时投递／恢复操作。
- 暂停、应用排除、记录上限及整包备份恢复；默认本机保存。

后续候选：连续复制／粘贴队列、轻量模板、主动开启的账号常用语同步。当前没有托管云服务、移动输入法或这些候选功能的完成声明。
