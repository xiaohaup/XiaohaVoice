# 隐私与网络行为

- 开始录音后，音频发给当前选择的语音服务进行识别；本地历史不等于离线识别。输入法兼容通道与火山API各自的服务方处理音频。
- 本机Data保存成功转写和统计字段、词库／草稿、配置及需手动恢复的未完成录音；成功录音不常规另存原音。
- 设备登记只在本人明确初始化后进行，随后复用。服务拒绝不循环换身份；不读取其他输入法的私有凭证。
- API密钥与同步会话进入系统安全存储，页面默认隐藏。完整ZIP备份不会导出这些密钥。
- 日志是可关闭的运行元数据，不写口述全文、音频或API密钥。请在提交问题前继续检查截图和日志中是否包含自己的资料。
- 账号服务组件默认没有部署。本人登录并开启后，按设置共享当前文字、词库、共享偏好和去重统计字段；历史全文、录音没有云端上传接口。服务端加密落盘，服务端持钥匙，不称端到端加密。
- 未来0.5剪贴板历史功能当前尚未实现；拟采用本机保存、主动开启和单独的同步授权，不把已有语音同步开关视为允许上传全部复制历史。
- 干净Release不包含作者个人Data、录音、词库、API凭证或设备身份。个人备份、真实账号配置、私人剪贴板内容不要提交到Git或Issue。
