# 账号同步组件

这一版保存可部署服务和五端网页入口，当前没有开通云服务或公网账号。

| 数据 | 同步范围 |
| --- | --- |
| 共享文字 | 账号内的当前文字；本人可选是否共享新转写 |
| 词库、共享偏好 | 账号同步，设备自己的快捷键与系统权限独立 |
| 总统计 | 录音编号、时间、字数、时长、设备标识；按编号去重 |
| 文字历史与录音 | 每台设备本机，不上传历史全文／原音 |

手机／平板网页支持本人点“复制”；不保证锁屏或浏览器后台自动写系统剪贴板。Mac、Windows 本机组件可在本人登录并开启后台同步后使用桌面剪贴板同步。

部署入口在 `sync-suite/deploy/`，先准备自己的 HTTPS 域名和服务器，再设置 PUBLIC_ORIGIN、持久化数据卷与注册开关。示例 `.env.example` 只有占位，不含真实密码或域名。服务端加密落盘，服务端持有解密密钥，不能称为端到端加密；备份需同时保存数据库和 master.key。

独立本机预览可在 `sync-suite` 内执行 `python run_server.py --preview`；仅监听本机。创建云资源、购买服务、开公网和五端实机联测均属于后续工作。
